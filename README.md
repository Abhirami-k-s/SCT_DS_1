# SCT_DS_1
Monthly Transaction Count Visualization using Tablea

This project presents a bar chart visualization of monthly transaction counts using an online shopping dataset.
### Dataset
The dataset contains transaction data including dates and customer purchase information.
### Visualization
- Bar chart showing the number of transactions for each month.
- Helps identify monthly trends in online shopping activity.
### Tools Used
- Tableau
### Objective
To visualize transaction distribution over months and demonstrate basic data visualization skills.
### Insight
The bar chart shows that **August has the highest number of transactions**, indicating a peak in online shopping activity during this month. This may be due to seasonal sales, festive offers, or promotional campaigns, while other months show comparatively lower transaction volumes.
